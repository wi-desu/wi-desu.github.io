プライバシーポリシー

最終更新日: 2026年10月12日

「こころの距離 制作」（以下「本ツール」）は、YouTubeチャンネル「こころの距離。大人の心理学」の運営者が、自分のチャンネルを運営するためだけに使う制作ツールです。

1. 使うGoogleのデータ

本ツールは、運営者本人のGoogleアカウントでのみ、YouTube Data API と YouTube Analytics API を使って、次のことを行います。

  • 運営者のチャンネルへの動画・サムネイルのアップロード
  • 運営者のチャンネルと動画の情報、再生数などの統計の読み取り
  • 公開されているYouTube動画の検索結果の読み取り（企画の調査のため）

2. 第三者のデータ

本ツールは、運営者以外の方のGoogleアカウントへのアクセスを求めることはなく、他の方の個人情報を集めません。

3. 保存と共有

認証情報は運営者のパソコンの中に暗号化して保存し、外部に送ったり、第三者に売ったり共有したりしません。取得した統計は、チャンネルの改善のためだけに使います。

4. Googleのポリシー

本ツールによるGoogle APIから受け取った情報の利用は、Google API Services User Data Policy（Limited Use の要件を含む）と YouTube利用規約 に従います。Googleのプライバシーポリシーもあわせてご確認ください。

5. アクセスの取り消し

本ツールへのアクセスは、Googleアカウントのセキュリティ設定からいつでも取り消せます。

6. お問い合わせ

YouTubeチャンネル「こころの距離。大人の心理学」のコメント欄からご連絡ください。
